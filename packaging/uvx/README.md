# Sidescope (`uvx` launcher)

Python wrapper for launching [Sidescope](https://github.com/mschulkind-oss/sidescope) on Linux Wayland desktops, with a built-in `doctor` command that checks for required system GTK4/libadwaita runtime libraries before executing the native binary.

```bash
uvx sidescope doctor
uvx sidescope --live
```
